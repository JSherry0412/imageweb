# Image Atelier · 本地生图工作台

一个运行在自己电脑上的生图工作台。连接兼容的图片服务，写下提示词、添加参考图，生成的作品就会保存在本地画廊。

**多套连接方案** · **多张参考图** · **Base64 自动转图** · **本地历史画廊**

---

## 开始使用

### 1. 启动工作台

需要先安装 **Python 3.10 或更高版本**。然后双击项目文件夹里的 `启动图片工作台.bat`，程序会检查并安装所需依赖，在后台启动服务并打开页面。

如果浏览器没有自动打开，访问 [http://127.0.0.1:7860](http://127.0.0.1:7860)。需要停止服务时，双击 `停止图片工作台.bat`。关闭启动窗口不会停止后台服务。

也可以在终端手动启动：

```powershell
python -m pip install -r requirements.txt
python app.py
```

### 2. 配置连接

在左侧「连接设置」中填写服务商提供的 **API Base URL、API Key、模型名称**，并根据服务商的说明选择接口类型和 API Path，最后点击「保存设置」。

可以为不同网站建立多套命名方案，以后从下拉列表切换即可。修改过配置后，记得保存再切换。API Key 保存在本机，不会显示在网页脚本中。

### 3. 开始生成

输入提示词，按需要选择图片数量、添加参考图和填写下载名称，然后点击「生成图片」。结果会出现在右侧画廊。也可以在提示词框内按 **Ctrl + Enter** 生成。

## 接口怎么选？

| 接口类型 | 默认 API Path | 适用情况 |
| --- | --- | --- |
| 图片生成接口 | `/images/generations` | 服务商提供兼容图片生成接口时使用；默认路径在添加参考图后会切换为 `/images/edits`。 |
| 聊天补全接口 | `/chat/completions` | 服务商通过聊天回复返回图片时使用；参考图以 data URL 发送。 |

API Path 可以自行修改，具体填写方式以服务商文档为准。模型对尺寸、参考图、生成数量和 `response_format` 的支持也取决于服务商。

如果网站返回的是类似 `![image](data:image/png;base64,...)` 的文本，开启「将 Markdown / Base64 自动转成图片」。标准图片接口返回的 `data[].b64_json` 和直接图片响应会自动处理。

## 创作与画廊

### 图片命名和数量

提示词上方可以填写下载名称，留空时使用随机名称。一次生成多张时会自动加上 `-1`、`-2` 等编号。每次可选择生成 **1–5 张**，默认 1 张；实际返回数量取决于服务商。

### 参考图

点击上传区域或将图片拖入，也可以复制图片后按 **Ctrl + V** 粘贴。支持分批添加、预览和单独移除，最多 16 张，每张不超过 20 MB。服务商和模型需要支持相应的图生图功能。

画廊图片和大图详情里都有「设为参考图」按钮，可以把现有作品追加到输入区。大图详情也会显示生成时保存的参考图，并可逐张再次使用；纯文字生成显示「当前无参考图」。旧历史如果没有保存参考图信息，会显示相应提示。

### 查看和管理作品

- 点击图片查看大图和完整提示词。按住 **Ctrl** 并滚动滚轮可缩放，放大后可按住鼠标左键拖动；不按 Ctrl 时滚轮照常滚动。
- 画廊卡片支持复制提示词、下载、设为参考图、放大和删除。大图中还可以查看和复制 Base64。
- 点击循环箭头可按原有提示词和接口设置重新生成，并**覆盖原图**。旧历史没有保存接口信息时会使用当前方案；使用原方案重生成时会读取该方案当前保存的密钥。
- 删除和覆盖图片前会弹出确认。生成等待状态只占用画廊中的待生成位置，其他区域仍可使用。
- 点击「图像工作室」旁的箭头可折叠左侧面板，点击页面左侧的箭头可展开。右上角可切换深色和浅色主题；两项选择保存在当前浏览器中。

## 文件保存在哪里？

工作台的数据保存在项目目录的 `data/` 文件夹中，关闭或重启服务后仍可读取。

| 位置 | 内容 |
| --- | --- |
| `data/images/` | 生成的图片 |
| `data/reference_sets/` | 用于记录和重生成的参考图副本 |
| `data/library.json` | 图片历史记录 |
| `data/profiles.json`、`data/settings.json` | 连接方案与设置，包含 API Key |

未下载的图片在生成 **7 天后**自动清理；下载过的图片会保留。关联图片全部删除或过期后，参考图副本会自动清理。需要长期保留的图片建议及时下载。

`data/` 包含个人图片、提示词和 API Key。请妥善备份该文件夹，避免将这些文件提交到公开仓库或分享给他人。服务默认只监听本机 `127.0.0.1`。

## 遇到问题

- **页面打不开**：确认已安装 Python、已运行启动 BAT，再访问 [http://127.0.0.1:7860](http://127.0.0.1:7860)。启动失败时可查看 `data/server-error.log`。
- **改动后仍看到旧页面**：重新启动工作台，然后在浏览器按 **Ctrl + F5** 强制刷新。
- **接口返回内容但没有图片**：确认接口类型、路径和模型是否与服务商要求一致；如果返回 Markdown/Base64 文本，开启自动转图选项。
- **切换方案后配置不对**：检查是否选中了预期方案，并在修改后点击「保存设置」。
