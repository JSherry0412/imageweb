# 本地生图工作台

一个运行在本机的图片生成网页，可连接 OpenAI 兼容的图片服务。支持文生图、多张参考图、Markdown/Base64 图片自动还原、历史记录管理、图片缩放预览和主题切换。

## 启动

1. 安装 Python 3.10 或更高版本。
2. 双击 `启动图片工作台.bat`，等待依赖安装并启动。服务会在后台运行，因此关闭启动窗口不会中断网页。需要完全停止服务时，双击 `停止图片工作台.bat`。
3. 浏览器打开 `http://127.0.0.1:7860`。

也可以在终端运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

首次使用时，在左侧配置 API 地址、密钥和模型。连接设置支持多套命名方案，可按网站预先保存后快速切换；原有设置会自动迁移为“默认方案”。方案、API 密钥、生成历史和图片保存在项目目录的 `data/` 中，关闭 BAT 只会停止本地服务，不会删除这些文件。不要删除 `data/` 文件夹。API 密钥不会发送到网页脚本或写入图片记录。

## 接口模式

- **图片生成接口**：默认使用 `/images/generations`；上传参考图时使用 `/images/edits`。
- **聊天补全接口**：使用 `/chat/completions`，解析文本回复中的 Markdown 图片/Base64 数据。参考图会作为 data URL 随消息发送。
- 可编辑 API 路径，以适配路径不同的兼容服务。
- “将 Markdown/Base64 响应转成图片”开启后，自动提取 `![...](data:image/...;base64,...)`、裸 data URL 或纯 Base64 图片。标准图片 API 的 `data[].b64_json` 与直接图片响应始终自动处理。

## 使用功能

- **生成数量**：在提示词区域选择每次生成 1–5 张，默认 1。图片生成接口通过 `n` 参数请求；聊天补全接口通过 `n` 请求多个回复。服务商可能不支持该参数或返回少于请求数量。
- **多张参考图**：可一次选择多张，也可分批添加；每张可预览并单独移除。从画廊将图片设为参考图会追加到列表；复制图片后也可在工作台按 Ctrl+V 粘贴添加。最多 16 张，每张不超过 20 MB。图片生成接口会将图片作为 multipart 文件发送，聊天补全接口会将图片作为 data URL 发送。服务商和模型需要支持多张参考图。
- **历史提示词**：画廊卡片展示提示词摘要，可悬停查看完整内容；点击卡片操作栏的复制按钮可复制提示词。生成等待状态只占用画廊中的待生成位置，不会遮挡其余图片和左侧操作。打开大图也能查看完整提示词。
- **图片预览**：点击画廊图片打开大图；详情中会显示生成时使用的参考图，并可一键添加回输入区；纯文字生成会注明“当前无参考图”。按住 Ctrl 滚动滚轮可缩放，放大后按住鼠标左键拖动查看其他区域。不按 Ctrl 时滚轮照常滚动。预览中还可下载图片、查看 Base64 或直接将图片设为参考图。
- **工作室折叠**：点击“图像工作室”旁的箭头隐藏左侧设置和输入区，让画廊占满页面；左侧展开箭头可恢复，选择会保存在浏览器中。
- **主题**：右上角可切换深色和柔和浅色主题。主题选择保存在当前浏览器中，默认使用深色。

尺寸、图生图以及 `response_format` 等参数的支持情况取决于服务商。

## 图片保留

生成图片保存在 `data/images/`，为支持按原条件重生成，参考图副本保存在 `data/reference_sets/`，并在关联图片全部删除或过期后自动清理。历史图片旁的循环箭头会按保存的提示词和接口设置重新生成并覆盖原图；旧历史没有接口快照时会使用当前选中的方案；新图片重生成时使用原连接方案当前保存的密钥，因此请保留原方案。删除和覆盖前都会弹出确认。未下载图片在生成 7 天后自动删除；下载过的图片会保留。图片卡片菜单可手动删除任意图片。

服务默认只绑定 `127.0.0.1`。不要把服务改为公开监听，也不要提交 `data/settings.json`、`data/profiles.json` 或个人生成图片。
